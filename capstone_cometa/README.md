# Attendance Checker (QR-based)

**Name:** Nino Lee Cometa Jr
**Workstation Number:** 12

## Project Description

Attendance Checker is a QR-based Flutter app that lets a teacher take attendance for one class section. The teacher starts a session, which displays a QR code. Students select their name and scan the code with their own phones to mark themselves present. The teacher can view the attendance list, see who is present or absent, and tap a student to mark them manually.

**Scope:** One class section only. The roster contains 10 dummy students. There is no report export.
